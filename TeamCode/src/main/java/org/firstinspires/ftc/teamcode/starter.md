## New Coders Start Here!

Welcome to the coding team! To begin to learn some code can read through the code samples from FTC themselves. 
In this Android Studio Project go to your project deck on the right and then FtcRobotController > Java > org.firstinspires.ftc.robotcontroller 
and read through some of the internal/external samples.

You can also read through [last year's teamcode](https://github.com/aurora-ftc/FTC_DECODE_23295_TEAMCODE/tree/State-Bot).
